# PHASE16.2 - Correcao de deploy/cache

## Entregas
- versao visivel em mais pontos da home
- banner de versao publicada
- botao para forcar limpeza de cache e atualizar a versao
- service worker com nova estrategia de cache e limpeza imediata
- build mais explicita para facilitar validacao do deploy

## Resultado
Reduz o risco de o site continuar mostrando build antiga por cache de navegador ou PWA.
